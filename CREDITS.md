# Credits

## Primary research corpus

Hermes Control Pack was bootstrapped using the structure and material collected in:

**System Prompts Leaks**  
Repository: https://github.com/asgeirtj/system_prompts_leaks  
Maintainer: `asgeirtj` and upstream contributors

The upstream repository performs the substantial work of collecting, organizing, and updating prompt/agent material across many vendors and products. HCP is a downstream Hermes-specific research/tooling project, not a replacement or mirror.

## Hermes Agent

Hermes Control Pack targets:

**Hermes Agent by Nous Research**  
Repository: https://github.com/NousResearch/hermes-agent

Hermes' context-file, skills, skill-bundle, delegation, terminal, and agent runtime capabilities make HCP's layered design possible. Hermes Agent itself is not bundled with HCP.

## Attribution policy

When HCP publishes a finding materially tied to a source family, preserve provenance in reports/metadata. Do not present captured third-party prompt text as original HCP authorship. HCP runtime text should remain a transferable, independently authored synthesis.
